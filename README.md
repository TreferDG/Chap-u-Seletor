# 🏰 Quiz Hogwarts - Chapéu Seletor (Python)

Este projeto é um **quiz interativo em Python** inspirado no universo de **Harry Potter**, onde o usuário responde algumas perguntas e, no final, descobre qual **Casa de Hogwarts** combina mais com sua personalidade.

As casas possíveis são:

- 🦁 **Grifinória**
- 🐍 **Sonserina**
- 🦅 **Corvinal**
- 🦡 **Lufa-Lufa**

---

## 📌 Objetivo do Projeto

O objetivo é praticar conceitos básicos e intermediários de Python, como:

- Entrada e saída de dados (`input()` e `print()`)
- Estruturas condicionais (`if`, `elif`, `else`)
- Estruturas de repetição (`while`, `for`)
- Uso de variáveis e contadores
- Listas e dicionários (opcional)
- Organização de código em funções (opcional)

---

## 🎮 Como funciona?

O programa faz uma sequência de perguntas para o usuário, e cada resposta soma pontos para uma casa específica.

No final, a casa com maior pontuação será a escolhida pelo **Chapéu Seletor**.

---
